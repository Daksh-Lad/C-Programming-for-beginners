# C Programming for Beginners

## About This Repository

This repository documents my journey of learning **C programming**, starting from the fundamentals and gradually progressing towards more advanced programming concepts.

The goal is to develop a strong foundation in programming, improve logical thinking, and build problem-solving skills through hands-on practice.

Rather than simply memorising syntax, I want to understand how programs work, how to approach problems logically, and how to write clean, readable, and efficient code.

Each problem is maintained in a separate `.c` file, with the question included at the beginning of the program and comments explaining important parts of the logic.

## Repository Structure

### 01 – Basics
C programming fundamentals, including:
- Printing output and taking user input
- Variables and data types
- Arithmetic and relational operators
- Conditional statements (`if`, `else`)
- Basic mathematical calculations
- Simple problem-solving programs

**Goal:** Build a strong foundation in C syntax and understand how basic programs are structured and executed.

### 02 – Loops and Numbers
Programs focused on repetition, mathematical logic, and number manipulation, including:
- `for` and `while` loops
- Factorial
- Reversing numbers
- Counting and summing digits
- Prime numbers
- Palindrome numbers
- Other number-based problems

**Goal:** Develop logical thinking and understand how loops can be used to solve repetitive and mathematical problems.

### 03 – Arrays
Programs involving collections of elements and array manipulation, including:
- Taking array input
- Finding the largest and smallest elements
- Reversing arrays
- Searching elements
- Sorting using Bubble Sort
- Counting even and odd elements
- Finding the second-largest element
- Merging arrays
- Other array operations

**Goal:** Understand how arrays store and organise data, and learn to manipulate and process multiple values.

### 04 – Strings
Upcoming topics:
- String length
- Reversing strings
- Palindrome strings
- Counting vowels and consonants
- Copying and comparing strings

**Goal:** Learn string handling and character-based operations in C.

### 05 – Functions and Pointers
Upcoming topics:
- User-defined functions
- Passing arguments and returning values
- Pointers
- Swapping values using pointers
- Recursion

**Goal:** Understand code modularity, memory addresses, pointers, and recursive problem-solving.

## Learning Approach

- Each problem is maintained as an independent C program.
- Programs are organised by topic and difficulty.
- Questions are included at the beginning of each source file.
- Comments explain important logic and decisions.
- The focus is on understanding the reasoning behind a solution, not just getting the correct output.
- As I progress, I will explore better approaches and improve code readability and efficiency.

## Progress

This repository will continue to grow as I learn new concepts and solve more programming problems.

**Starting with the basics, building strong logic, and progressing towards advanced programming.**
